# lty-admin-go 后台管理系统

这是一个基于 Go (Gin) 和 Vue3 (Element Plus) 构建的美观且规范的后台管理系统。系统支持**可视化安装向导**，无需手动修改代码配置，即可轻松完成数据库的连接与初始化。

## 项目结构说明

所有的后端代码包名、数据库表名等均遵守规范，带有 `lty_` 前缀。

## 运行与安装指南

运行了`npm install` 为您安装了所有项目依赖

### 1. 启动 Go 后端服务

首先需要启动后端的接口服务。请打开一个终端，执行以下命令：

```bash
cd hd/lty_backend
go run lty_main.go
```

启动成功后，终端会显示服务运行在 `:8080` 端口。

> **注意**：首次启动时由于尚未配置数据库，后端会自动进入“待安装”模式，这是正常现象。

### 2. 启动 Vue3 管理后台前端界面

请打开一个**全新的终端**（不要关闭后端的终端），执行以下命令启动管理后台开发服务器：

```bash
cd hd/lty_admin_ui
npm run dev
```

### 3. 启动 Vue3 面向用户前台界面

请再打开一个**全新的终端**，执行以下命令启动前台展示界面的开发服务器：

```bash
cd qd
npm run dev
```

### 4. 进入可视化安装向导

安装成功后，系统会自动跳转至登录页面，代表系统环境已经全部配置完毕，可以开始正式使用了！

## 编译打包指南 (前端与后端)

如果您需要将项目编译打包以供部署，请按照以下步骤分别对前端和后端进行编译：

### 1. 前端编译打包 (管理后台与用户前台)

前端项目使用 Vue3 + Vite 构建，打包后会生成可直接部署的静态网页文件。

**打包管理后台：**

```bash
cd hd/lty_admin_ui
# 安装依赖（如果尚未安装）
npm install
# 执行编译打包
npm run build
```

打包完成后，会在 `lty_admin_ui` 目录下生成 `dist` 文件夹。

**打包用户前台：**

```bash
cd qd
# 安装依赖（如果尚未安装）
npm install
# 执行编译打包
npm run build
```

打包完成后，会在 `qd` 目录下生成 `dist` 文件夹。

这两个 `dist` 文件夹内包含了所有的前端静态资源（html、css、js、图片等）。这些文件都可以直接部署到 Nginx、Apache 或宝塔等任何 Web 服务器。

### 2. 后端编译打包

后端项目基于 Go 开发，支持跨平台编译。您可以直接将其编译为不需要额外运行环境的独立可执行文件。

```bash
cd hd/lty_backend

# 【编译为 Windows 系统可执行文件】
go build -o lty_main.exe lty_main.go

# 【在 Windows 下交叉编译为 Linux 系统可执行文件】(常用于部署到 CentOS/Ubuntu/宝塔等服务器)
$env:GOOS="linux"
$env:GOARCH="amd64"
go build -o lty_backend_app lty_main.go
```

编译完成后，当前目录下会生成 `lty_main.exe` (Windows) 或 `lty_backend_app` (Linux) 可执行文件。部署时只需将该文件上传到服务器并运行即可。
